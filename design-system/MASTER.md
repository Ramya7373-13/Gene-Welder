# MutationMechanic — Design System MASTER
> Generated by ui-ux-pro-max v2 · Clinical/Bioinformatics Dashboard · Dense dark theme
> Stack: React 18 + TypeScript + Vite + Tailwind utility classes + Lucide React icons

## 1. Design Philosophy

**Pattern:** Real-Time / Operations Dashboard  
**Style:** Glassmorphism Dark — frosted glass layers, subtle borders, depth via backdrop-blur  
**Priority:** Data density over decoration. Legibility first. Clinical context demands zero ambiguity.

### Reusable Tactical Classes:
- `.mm-glow`: Base luminous border container with outer glow and subtle inner glow.

- `.mm-section-accent`: Luminous pill accent (`h-1.5 w-10`) next to tactical uppercase section titles.
- `.mm-dna-backdrop`: Ultra-faint (`opacity: 0.045` $\to$ `0.08` hover) SVG sinusoidal double-helix strand drifting inside card containers (disabled in `prefers-reduced-motion`).

## 5. Component Anatomy

### 5.1 Cards (Variant Cards, Benchmark Cards)

```
┌─ border-[--color-border] rounded-xl bg-[--color-card] ──────────┐
│  Header row:  [gene name bold]  [UniProt ID badge right]         │
│  Sub row:     [HGVS mono teal]                                   │
│  Body:        [disease label muted]  line-clamp-1                │
│  Footer:      [optional action chips]                            │
└─────────────────────────────────────────────────────────────────┘
```

**Interaction states:**
- Default: `border-[--color-border]`
- Hover: `border-[--color-primary]/40 bg-[--color-card-hover] shadow-lg shadow-[--color-primary]/5 -translate-y-0.5`
- Active/pressed: `scale-[0.98] shadow-inner`
- Selected (compare mode): `border-[--color-primary] ring-1 ring-[--color-primary] bg-[--color-primary-dim]`
- Focus-visible: `outline-none ring-2 ring-[--color-ring] ring-offset-2 ring-offset-[--color-background]`

**Transition:** `transition-all duration-200 ease-out`

### 5.2 Filter Chips (All / Frameshift / Splice / Folding / Custom)

```html
<button
  role="button"
  aria-pressed="true|false"
  className="chip chip--active | chip"
>
  Label
</button>
```

States:
- Default: `bg-[--color-muted] text-[--color-foreground-secondary] border border-[--color-border]`
- Hover: `border-[--color-primary]/50 text-[--color-foreground]`
- Active/selected (`aria-pressed="true"`): `bg-[--color-primary-dim] border-[--color-primary] text-[--color-primary] font-semibold`
- Focus-visible: `ring-2 ring-[--color-ring] ring-offset-1 ring-offset-[--color-background]`

### 5.3 Navigation Tabs (main: Explainer / Design / Tracer / Splicing / Analytics)

- Tab list background: `bg-slate-900/60 backdrop-blur-sm border border-[--color-border-subtle]`
- Inactive: `text-[--color-foreground-secondary] hover:text-[--color-foreground] hover:bg-slate-800`
- Active: `bg-[--color-primary] text-slate-900 font-semibold shadow-lg shadow-[--color-primary]/20`
- Focus-visible: `ring-2 ring-[--color-ring] ring-offset-2 ring-offset-slate-900`

### 5.4 Sub-tabs (Overview / Hotspots / Temporal / Stats and others)

- Container: `flex bg-slate-900/50 rounded-lg p-0.5 border border-slate-800`
- Inactive: `text-slate-400 hover:text-white hover:bg-slate-800`
- Active: `bg-[--color-primary]/10 text-[--color-primary] border border-[--color-primary]/30`
- Transition: `transition-all duration-150`

### 5.5 Dropdowns / Selects

All `<select>` elements must have:
- Background: `bg-slate-950 border border-[--color-border]`
- Text: `text-[--color-foreground]`
- Hover: `border-[--color-primary]/50`
- Focus: `border-[--color-primary] ring-2 ring-[--color-primary]/20 outline-none`
- Chevron indicator: append `bg-[url(...)] bg-no-repeat bg-right` or wrap in a `relative` div with a `<ChevronDown>` icon absolutely positioned
- Disabled (empty): `opacity-50 cursor-not-allowed`
- Padding: `pl-3 pr-8 py-2` (room for chevron)

### 5.6 Buttons

| Variant | Classes |
|---|---|
| Primary | `bg-[--color-primary] text-slate-900 hover:bg-[--color-primary-hover] font-semibold` |
| Secondary | `bg-slate-800 border border-[--color-border] text-[--color-foreground] hover:bg-slate-700 hover:border-[--color-primary]/40` |
| Destructive | `bg-[--color-destructive-dim] border border-[--color-destructive]/30 text-[--color-destructive] hover:bg-[--color-destructive]/20` |
| Ghost | `text-[--color-foreground-secondary] hover:text-[--color-foreground] hover:bg-slate-800` |

All buttons: `rounded-lg px-4 py-2 text-sm font-medium transition-all duration-150 focus-visible:ring-2 focus-visible:ring-[--color-ring] focus-visible:outline-none active:scale-[0.97] cursor-pointer`

## 6. Empty States

Pattern: icon (muted, 48px) → headline (foreground) → subtext (muted) → optional CTA

```tsx
<EmptyState
  icon={IconComponent}          // Lucide icon
  headline="No data yet"
  subtext="Run an analysis to see results here."
  action={{ label: "Run first analysis", onClick: handler }}  // optional
/>
```

**Anti-pattern to avoid:** Raw `"0"` or blank cells. Zero-value stats must include context:  
- "Total Patients: 0" → styled with muted value + "No patients added yet" subtext + "New Patient" CTA

## 7. Destructive Action Safety

**Rule:** Any action that deletes data permanently (Wipe History, Delete Record) MUST use the `<ConfirmModal>` component, not `window.confirm()`.

```tsx
<ConfirmModal
  isOpen={showConfirm}
  onClose={() => setShowConfirm(false)}
  onConfirm={handleDestructiveAction}
  title="Wipe All History?"
  description="This will permanently delete all analysis records and audit data. This action cannot be undone."
  confirmLabel="Wipe History"
  variant="destructive"
/>
```

`window.confirm()` is permissible only for low-stakes actions like deleting a single preset.

Reusable across all pages that communicate backend connectivity.

```tsx
<StatusBanner status="connected" message="Connected to clinical backend" count={42} />
<StatusBanner status="disconnected" message="Backend offline — running in simulation mode" />
```

Position: bottom of panel / above table, not in page header.

## 9. Motion

- Reduced-motion: always wrap animations in `motion-safe:` Tailwind variant or check `prefers-reduced-motion`
- Card hover lift: `transition-transform duration-200 hover:-translate-y-0.5`
- Tab switch: `animate-in fade-in slide-in-from-bottom-2 duration-200`
- Modal open: `animate-in fade-in zoom-in-95 duration-150`
- Empty state: `animate-in fade-in duration-300`

## 10. Anti-Patterns Flagged

| Anti-Pattern | Location | Fix |
|---|---|---|
| `window.confirm()` for destructive wipe | AnalyticsDashboard, CompensatoryDesignTab | Replace with `<ConfirmModal>` |
| Emoji as structural icons (📖⚡🔬🧬) | App.tsx TabsTrigger | Replace with Lucide SVG icons |
| Static chips with no `aria-pressed` | CompensatoryDesignTab, AnalyticsDashboard | `<button aria-pressed>` |
| "Total Patients: 0" looks broken | HistoryTable | EmptyState with CTA |
| No visible focus ring on cards | VariantExplainerTab | `focus-visible:ring-2` |
| `text-slate-500` on `bg-slate-900` (3.1:1) | Multiple | Upgrade to `text-slate-300` for content text |
| Neumorphic light shadows on dark bg | index.css | Remove; replace with dark-native shadow tokens |
| Inline `style=` for widths/colors | DiseaseTracerTab | Use CSS class utilities |
